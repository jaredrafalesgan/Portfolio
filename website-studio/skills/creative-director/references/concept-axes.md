# Divergence axes

Three concepts must differ on at least three of these axes. Pick a position on each deliberately; don't leave one on its default by accident.

| Axis | Pole A | ↔ | Pole B |
|---|---|---|---|
| Density | Sparse, gallery-like | | Dense, information-rich, editorial |
| Grid | Strict modular grid | | Broken / collage / free placement |
| Symmetry | Centered, formal | | Asymmetric, tension |
| Type voice | Text-led, typography as image | | Image-led, type recedes |
| Type genre | Grotesk / neo-grotesk | | Serif / slab / display / mono / script |
| Color temperature | Cool, mineral | | Warm, organic |
| Color strategy | Monochrome + one accent | | Full palette, color-blocking |
| Value | Light ground | | Dark ground (or alternating sections) |
| Surface | Flat, ink-on-paper | | Depth, layering, material texture |
| Edges | Sharp, 0 radius | | Soft, generous radius (with hierarchy) |
| Imagery | Photography (documentary, real) | | Illustration / 3D / type / data-viz |
| Image framing | Full-bleed | | Contained, framed, cut-out |
| Motion | Still and confident | | Kinetic, scroll-choreographed |
| Navigation | Conventional top bar | | Index, sidebar, overlay, in-content |
| Tone of copy | Plain, factual | | Voice-led, witty, opinionated |
| Era reference | Contemporary digital | | Specific historic reference (Swiss 60s, 70s print, Bauhaus, Memphis, early web…), translated, not costumed |
| Scale contrast | Even, calm | | Extreme (huge vs. tiny) |

## Reference genres to borrow *thinking* from (not looks)

- **Editorial / magazine:** pacing across a spread, pull quotes, captions as content, image-text interplay.
- **Swiss / International:** grid as meaning, flush-left rag, asymmetric balance, objective photography.
- **Museum & exhibition:** wall text, object labels, generous negative space, wayfinding.
- **Product packaging:** information hierarchy at small size, materials, regulatory detail as texture.
- **Signage & wayfinding:** legibility at distance, pictograms with function, color as code.
- **Film title design:** sequence, reveal, timing, type in motion.
- **Scientific / technical documents:** figures, annotations, tabular precision.
- **Print ephemera:** tickets, receipts, labels, stamps, perforations — when the subject owns them.

## Quick sanity test per concept

1. Describe it to someone without saying the client's name. Could they guess the industry? (good)
2. Could they guess it's "a startup landing page"? (bad: you've described a template)
3. Is there one thing a visitor would mention to a friend? (that's the signature)
