How I build a workflow

The same four steps, whether it’s one reminder or a full customer journey.

  1. 1

    Map the journey

    Every moment a lead or customer should hear from you, and what happens if they don’t respond.

  2. 2

    Set triggers and tags

    Forms, links and bookings start the workflow. Tags record where each contact is, so the CRM always knows.

  3. 3

    Time the follow-up

    Waits, business hours and time zones, so messages arrive when people will actually read them.

  4. 4

    Test every branch

    Test contacts go down each path, and I check the execution logs before anything is published.
