How I build a workflow

The same four steps, whether it’s one reminder or a whole customer journey.

  1. 1

    Map the journey

    Every moment a contact should hear from you, and what happens if they don’t respond.

  2. 2

    Set triggers and tags

    Forms, links and bookings start the workflow; tags tell the CRM where each contact is.

  3. 3

    Time the follow-up

    Waits, business hours and time zones, so messages arrive when people read them.

  4. 4

    Test every branch

    Test contacts down each path and a check of the execution logs before publishing.
