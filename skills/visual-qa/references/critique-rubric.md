# Creative director critique rubric

Score each dimension 1–5 from the screenshots (not the code). 5 = would appear on an awards gallery; 4 = a senior agency designer would sign it; 3 = competent but forgettable; 2 = visibly templated or flawed; 1 = broken.
Ship threshold: every dimension ≥ 4.

| # | Dimension | Questions | Score | Finding → fix |
|---|---|---|---|---|
| 1 | **Identity** | Is it unmistakably *this* client? Swap test: put a competitor's logo on it. Does it break? Is the signature element present and memorable? | | |
| 2 | **Hero clarity** | In 5 seconds at mobile and desktop: what is it, who is it for, what do I do? Is the most characteristic thing in the subject's world shown? | | |
| 3 | **Typography** | Distinctive, appropriate faces? Real scale contrast? Good measure, rag, line breaks in headlines? Hierarchy readable when squinting? | | |
| 4 | **Composition & grid** | Shared alignment edges? Intentional asymmetry/breaks? One focal point per screen? No orphan grid items at tablet? | | |
| 5 | **Rhythm & pacing** | Do sections vary in density, width, and value? Any two adjacent sections that look the same? Does the page have a beginning, middle, and end? | | |
| 6 | **Spacing** | Tokens used consistently? Related things grouped, groups separated? Anything cramped (esp. mobile padding) or floating? | | |
| 7 | **Color & imagery** | Palette tuned and restrained? Accent reserved for action? Images authentic, consistently treated, well cropped at every breakpoint? | | |
| 8 | **Detail & craft** | States designed (hover/focus/active)? Icons optically aligned? Consistent radii and borders? Favicon, selection, 404, footer considered? | | |
| 9 | **Motion** (watch it or review the inventory) | Does each animation have a job? One signature moment? Smooth, interruptible, no jank, reduced-motion respected? | | |
| 10 | **Mobile experience** | Re-composed (not squashed)? Thumb-reachable CTA, legible type, menu that feels designed? Equal polish to desktop? | | |

## AI-tell sweep (any "yes" caps Identity at 3 until justified)
- [ ] Purple/blue gradient, gradient text, glow blobs
- [ ] Identical rounded cards with soft shadows
- [ ] Centered hero + two pill buttons + browser-frame screenshot
- [ ] Icon + 3-word title + 1-line description × 3
- [ ] Eyebrow label above every heading
- [ ] Fade-up on every section
- [ ] Generic stock imagery or vague copy ("Elevate your…")

## The final questions
1. Would a senior designer at a respected studio put this in their portfolio?
2. If I removed one element (Chanel's rule), would it be better? Remove it.
3. What is the one thing a visitor will remember? If you can't name it, the identity score is ≤ 3.
