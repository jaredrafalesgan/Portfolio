# Creative concepts — Portfolio

All three are dark, premium and technical per the brief. They differ on layout, type voice, imagery and motion.

---

## A — "Live Workflow"  ★ recommended
**Idea:** The site runs like one of his automations. The hero is a working workflow: a lead fills a form, gets tagged, waits, receives an SMS reminder, books a call. Each node lights up in sequence and a timestamped run log ticks underneath. Every case study is then presented as a "run": trigger → steps → outcome.

- **Palette:** Graphite `#12151A` (ground) · Panel `#1A1F26` · Line `#2A313B` · Bone `#ECE8E1` (ink) · Mist `#9AA3AE` (secondary) · **Signal blue `#3D7BFF`**, used only for live and active states and the primary CTA (continuity with his old brand blue).
- **Type:** *Schibsted Grotesk* (display, tight, newsy-technical) + *Geist* (text) + *Geist Mono* only inside the workflow and run log, where it is real system output.
- **Layout:**
```
┌──────────────────────────────────────────────────────────────┐
│ Jared Gan            Systems  Thinking  Experience  Contact   │
│                                                              │
│ I build the follow-up      ┌─ Form submitted ──┐             │
│ that runs itself.          │  ↓ Tag: webinar    │  ← nodes    │
│                            │  ↓ Wait 1 day      │    light up │
│ GoHighLevel & marketing    │  ↓ SMS reminder ●  │             │
│ automation specialist      │  ↓ Appointment ✓   │             │
│ [Start a project]          └────────────────────┘             │
│                            09:00:02  sms.sent  → +1 ••• 4410  │
├──────────────────────────────────────────────────────────────┤
│ Webinar system  ────────────────────────────────────────────  │
│ [large real screenshot, annotated]   Trigger / Steps / Result │
└──────────────────────────────────────────────────────────────┘
```
- **Imagery:** real GHL screenshots, cropped to the interesting part and annotated with thin leader lines; his portrait once, in About.
- **Signature:** the live workflow hero. It shows his skill instead of claiming it, and it's built from his own domain.
- **Motion:** one choreographed hero run (about 4s, then it idles). Hover on a workflow node reveals what it does. Everything else is still. Under reduced motion, the workflow renders complete and static.
- **Risk:** dark plus mono can drift toward "developer terminal" cliché. Mitigated by editorial type scale, warm "bone" ink instead of pure white, and real screenshots.

## B — "Field Notes"
**Idea:** A premium consultant's casebook. Editorial magazine pacing: big serif headlines, each system a spread with a large screenshot, captions and marginalia explaining decisions.

- **Palette:** Ink navy `#0F1420` · Paper white `#F2EEE6` text · Brass `#C9A86A` hairlines and accents.
- **Type:** *Newsreader* display (optical sizes) + *Public Sans* text.
- **Layout:** asymmetric spreads: image bleeding off one edge, caption column on the other; chapter numbers for the five systems (a real sequence).
- **Signature:** marginalia annotations on screenshots, in his voice ("This wait step stops reminders landing at 3am").
- **Motion:** almost none; a page-load title reveal only.
- **Risk:** feels premium but less technical; the serif-on-dark consultant look is common in agency sites.

## C — "Pipeline"
**Idea:** The page is a CRM pipeline. As you scroll, "you" move through stages: New lead → Qualified → Proposal → Booked. Each stage reveals a capability; the contact form is the final stage, "Booked".

- **Palette:** Charcoal `#141414` · Concrete `#D9D6D0` · Stage colors (four muted hues for pipeline stages) · Accent for "Booked".
- **Type:** *Archivo* (variable width, expanded headlines) + *IBM Plex Sans*.
- **Layout:** horizontal stage rail pinned at top on desktop; content cards move along stages.
- **Signature:** the pipeline progress rail, with the contact form as the final stage.
- **Motion:** scroll-linked, choreographed throughout.
- **Risk:** gimmicky; heavier scroll animation hurts mobile and accessibility; the metaphor can upstage the work.

## Anti-AI pre-flight on A
- Dark + one accent: legitimate here (brief asks for dark), but the accent is his existing brand blue, used only for state, not an acid green. ✔
- Mono face: restricted to genuine system output (workflow and log). ✔
- No gradients, glows, glass, card grids, or emoji icons; tools named in context, not as a logo strip. ✔
- Numbered "01 / 02" on case studies: drop it unless the order means something. Use system names instead. ✔
- Swap test: put a competitor's name on it and the workflow, cases and voice no longer fit. ✔
