## 1 — GoHighLevel (category)
Blue gradient hero, product dashboard collage, stat counters, award badges, mascot robot, comparison table, pricing cards, testimonial cards, integration logos. **Convention:** SaaS-blue + dashboard collage + badges. Clients in this space have seen it endlessly; a specialist site that looks like GHL marketing reads as a reseller.

## 2 — Make (category)
Purple gradients, glass cards, floating UI chips, stock photography of hands on keyboards. **Anti-reference:** this is the exact "AI automation" aesthetic to avoid.

## 3 — Linear (excellence)
| Dimension | Decision | Effect |
|---|---|---|
| Hero | Real product UI, large and legible, as the hero image | Proves capability instantly |
| Type | Restrained sans, large but calm; muted secondary text | Premium without shouting |
| Rhythm | Sections alternate statement → real UI → small feature list | Calm pacing, dense where needed |

**Principle:** *Show the actual system at a legible size; let it be the hero rather than decoration.*

## 4 — Brittany Chiang (excellence, portfolio)
Sticky left column (identity + section index), right column scrolls through about, experience timeline, projects. **Principle:** *a persistent index lets a dense specialist portfolio stay navigable.* Caution: this layout is widely cloned; borrow the persistent-index idea, not the look.

## Category conventions
| Convention | Meet / Break | Why |
|---|---|---|
| Tool logo strip (GHL, Zapier, Make…) | Break: name tools in context of what was built | Logos are what VAs do |
| Animated stat counters | Break: real numbers, static, sourced | Old ones showed "0+" |
| Skills grid with icons | Break | Template signal |
| Screenshots as proof | Meet, at legible size with annotations | The strongest proof he has |
| Blue as "tech" color | Partly meet: blue continuity with his old brand, used as a signal only | Recognisable, but not SaaS-blue washes |
| Contact via form | Meet | Primary action |

## Anti-references
SaaS-blue gradient washes; purple glass; robot mascots; dashboard collages; generic "automation" stock photos; equal-weight design + automation positioning.

## Principles carried into direction
1. **The system is the hero.** Show a workflow working, not adjectives about workflows.
2. **Every claim is evidence.** Real numbers, real screenshots, real roles, captioned.
3. **Explain the thinking.** Challenge → build → result, in plain language, is what separates a specialist from an operator.
4. **Dense but navigable.** A persistent index on desktop; a clean single column on mobile.
